A document just arrived in the operator's inbox folder; its text is attached. Write a short
Markdown note for a busy small-business owner:

# <what the document is, e.g. "Invoice from Acme, March">

## Key facts
Bullets with the facts that matter: parties, amounts with currency, dates, reference numbers
(an invoice or order number often sits in the title line). Copy numbers and dates exactly as written.

## What you need to do
One bullet per action, each with a deadline when the document gives one ("Pay €1,240 by
14 October"); for an invoice, the action is paying the total due, once. If nothing is needed, say
"Nothing to do; filed for reference."

## Watch out
Only if something is unusual (a changed price, a penalty clause, a missing signature). Otherwise
leave this section out.

Use only the document. Never invent a fact, an amount or a date. If several documents are
attached, write one note per document, one after the other.
